Bertindaklah sebagai Senior Flutter Developer dan UI/UX Designer. Saya sedang membuat aplikasi Android bernama Fem-PhysicsMonitor. Fitur utama aplikasi ini adalah mendeteksi emosi pengguna melalui suara (Happy, Sad, Angry, Disgust, Neutral, Fear) dan memonitor keadaan psikis serta riwayat perkembangannya.

Saat ini, saya hanya membutuhkan kode untuk tampilan antarmuka (UI) saja, tanpa logika backend atau integrasi model ML. Buatkan struktur UI yang modular, rapi, dan responsif.

Gaya Desain:
Modern, clean, menggunakan Material 3, dan gunakan palet warna yang menenangkan (seperti pastel, biru lembut, atau hijau mint) karena ini adalah aplikasi psikologi.

Tolong buatkan kode Flutter untuk 3 halaman utama berikut, lengkap dengan navigasinya (BottomNavigationBar):

1. Dashboard / Home Screen:

Ucapan selamat datang.

Kartu (Card) ringkasan kondisi psikis hari ini berdasarkan deteksi terakhir.

Tombol utama (Floating Action Button atau tombol besar di tengah) yang menarik (Call-to-Action) untuk mulai merekam suara.

Cuplikan (snippet) riwayat deteksi emosi terbaru.

2. Voice Detection Screen (Layar Perekaman & Hasil):

Tampilan antarmuka saat pengguna merekam suara (buatkan elemen UI seperti animasi gelombang suara/visualizer statis atau tombol mikrofon yang sedang aktif).

Bagian hasil deteksi yang menampilkan visual yang jelas untuk emosi yang terdeteksi (Happy, Sad, Angry, Disgust, Neutral, Fear) menggunakan ikon atau warna yang representatif.

Pesan singkat terkait kondisi psikis berdasarkan emosi tersebut.

3. History / Progress Screen:

Tampilan riwayat perkembangan emosi pengguna dari waktu ke waktu.

Buatkan representasi grafik (Anda bisa menggunakan dummy code untuk grafik bar atau line chart, seolah-olah menggunakan package fl_chart).

Daftar (ListTile) log emosi sebelumnya beserta tanggal dan waktunya.

Instruksi Tambahan:
Gunakan dummy data (data palsu) untuk semua variabel, riwayat, dan hasil agar saya bisa melihat gambaran penuh dari UI-nya. Berikan kodenya secara lengkap dan beri komentar pada bagian yang penting.
